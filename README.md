# КіберМаркет

Онлайн-продаж великої та дрібної побутової техніки з доставкою по місту й самовивозом.

## Функції

- Пошук товару в каталозі й додавання до кошика.
- Оформлення замовлення з вибором способу доставки та оплати.
- Резервування товару на складі.

## Перевірка стилю коду

Код перевіряє лінтер flake8 під час кожного pull request.
